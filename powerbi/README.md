# Power BI Dashboard

The final Power BI report should be saved locally as:

`foam_quality_dashboard.pbix`

1. **Executive Quality Overview**

Management-level summary of:

- Production Quantity
- Defect Quantity
- Defect Rate
- First Pass Yield
- Cost of Quality
- Monthly Defect Rate Trend
- Product Performance
- Machine Performance
- Defect Type Pareto
- Batch Quality Status
