# Data

## Data source

This project uses a **synthetic foam-manufacturing dataset** created for educational and portfolio purposes. It does not contain actual company data.

## Business scenario

A fictional foam manufacturer wants to understand quality performance across products, machines, shifts, defects, environmental conditions, maintenance age, and process cycle time.

## Analytical caution

Relationships observed in the synthetic data should be described as associations rather than proven causal relationships. Machine, shift, humidity, maintenance age, and cycle-time differences should be investigated further before operational decisions are made.
